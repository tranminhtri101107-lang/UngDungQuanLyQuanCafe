# ☕ HUTEA POS - Phần mềm Quản lý Quán Cafe

Dự án phần mềm quản lý quán cafe toàn diện, được thiết kế để tối ưu hóa quy trình vận hành thực tế tại cửa hàng, từ khâu phục vụ khách hàng, quản lý kho nguyên liệu đến quản trị nhân sự.

## 🌟 Tính năng cốt lõi

### 1. Phân hệ Bán hàng & Vận hành (Sales & Operations)
* Quản lý thực đơn (Menu) đồ uống và bảng giá.
* Giao diện bán hàng (POS) trực tiếp tại quầy, thao tác nhanh gọn.
* Tính tiền, in hóa đơn và quản lý doanh thu theo ca.

### 2. Phân hệ Quản trị Nhân sự (HR Management)
* **Tuyển dụng:** Xử lý quy trình tuyển dụng và cấp tài khoản qua bảng tạm (Admin duyệt đơn).
* **Phân ca linh hoạt:** Xếp ca làm việc cho nhân viên theo tuần/tháng.
* **Chấm công & Lương:** Ghi nhận giờ làm, chốt lương cuối tháng tự động.
* **Xử lý đơn từ:** Quản lý các yêu cầu nghỉ phép, đổi ca của nhân viên.

### 3. Phân hệ Quản lý Kho (Inventory)
* Kiểm soát chặt chẽ quá trình xuất/nhập kho nguyên liệu.
* Cảnh báo tồn kho tối thiểu.

## 💻 Công nghệ sử dụng
* **Ngôn ngữ:** Java
* **Giao diện:** Swing / JavaFX
* **Cơ sở dữ liệu:** MySQL
* **Kiến trúc:** MVC (Model - View - Controller)

## 🚀 Hướng dẫn cài đặt
1. Clone repository này về máy: `git clone https://github.com/tranminhtri101107/Ten-Repo-Cua-Ban.git`
2. Import database từ file `database.sql` đính kèm vào MySQL.
3. Mở project bằng IDE (IntelliJ IDEA / Eclipse / NetBeans).
4. Cấu hình lại thông tin kết nối database (chuỗi kết nối, username, password) trong source code.
5. Build và Run project.
